## Website-to-platform connection lane

Every campaign that sends a person from social media or email to a LEAPcares website must record the connection in the private campaign owner before release. Keep provider IDs and restricted configuration out of this public repository.

1. Name the exact public domain and route, the existing website owner, and the Consolve location/site/page/form records used behind it.
2. Label the relationship accurately as one of:
   - **navigation link** — the website only links to another destination;
   - **embedded provider form** — the page loads a Consolve form, but post-submit behavior is not yet proven;
   - **verified workflow** — a private synthetic test proved save/receipt/routing with outbound notices suppressed; or
   - **synchronization** — only after the actual field mapping, authority, error handling, and readback are tested.
3. Preserve the existing page, form, submission history, stable IDs, permissions, and rollback/version history. Do not replace a record merely because its mapping is incomplete.
4. Verify the public route, approved Privacy and Terms destinations, minimum-necessary fields, consent language, confirmation state, operational recipient/owner, and private record authority.
5. Use a harmless synthetic adult fixture for testing. Suppress email, SMS, push, invitations, charges, and real-person matching before submission. Never test with a child, family, learner, donor, or participant record.
6. Record the test result as PASS, FAIL, or NOT TESTED. A visible form, saved draft, successful page load, or sample dashboard is not proof of routing or synchronization.

## ADDIE-H run

Use one stable campaign ID and append evidence to the existing owner.

### A1 Analyze

1. Recover the current owner, checkpoint, audience, objective, approved offer, and exact source versions.
2. Verify the actual Consolve location, connected channel identities, destination URLs, consent boundary, and current provider state.
3. Separate facts, inferences, hypotheses, and unresolved questions.
4. Record holds. A missing donation route, privacy page, permission, or claim blocks only the dependent item.

### D1 Design

1. Define the people served, intended outcome, acceptance checks, and smallest useful channel set.
2. Reuse existing approved content before generating new material.
3. Choose the smallest suitable repository skills. Common sequence: product-marketing → content-strategy → copywriting/emails/social → analytics or conversion-tracking when a verified destination exists.
4. Preserve separate giving, scholarship, and free-entry drawing processes. Never use participant data as a marketing product.

### D2 Develop

1. Prepare copy, accessibility text, media provenance, subject line, channel variants, source links, and a rollback note.
2. Apply the current LEAPcares brand standard: approved artwork unchanged, Dr. Suz Leora credit, Published By Leorain Education™, approved palette, source-verified DejaVu typography where supported, and meaningful captions/transcripts for audio or video.
3. Keep private drafts free of recipients and schedules until review is complete.
4. Record incremental cash cost, staff time, platform fees, maintenance, privacy impact, and delivery capacity. Unknown remains unavailable.

### I1 Implement

1. Run private synthetic rehearsal first.
2. Save the reviewed draft in Consolve and read it back from the live destination.
3. Verify exact channel identities before connecting or posting.
4. Do not create new accounts, reconnect OAuth permissions, publish, schedule, send, spend, or expand recipients without the applicable current approval.
5. When a website route is used, complete the website-to-platform connection lane and retain the private provider receipt in the existing owner.

### E1 Evaluate

Check and record:

- correct campaign and owner;
- exact copy and approved artwork;
- links, privacy, consent, and truthful conversion receipt;
- exact website/Consolve identities, connection type, form routing, and post-submit owner;
- learner/participant privacy and no sensitive data in public URLs or events;
- keyboard, mobile, caption, transcript, and alt-text behavior where applicable;
- provider state: prepared, internally checked, provider-saved, scheduled, published, delivered, accepted, or measured.

Do not treat a draft, button click, screenshot, sample dashboard, or forecast as delivery or results.

### H1 Harvest

After verified destination readback, append the artifact version, provider receipt, actual results, cost/time, lessons, rollback, and next action to the existing owner. Promote only reusable, reviewed learning to the Grove canon and this public-safe recipe.

## Release gate

Before any Consolve send or social publication, the owner must have:

- exact audience and recipient authorization;
- verified destination and claims;
- approved final copy and media;
- accessibility review;
- privacy/consent check;
- channel identity confirmation;
- rollback/correction path;
- action-time approval when the release represents LEAPcares publicly.

If any item is unresolved, retain the artifact as **DRAFT / HOLD** and continue independent safe work.
